✈️ TravelHub

A full-stack travel booking platform where users can search and book tour packages, flights, hotels, and car rentals.

🌍 Destinations

Nepal

Dubai

🧰 Tech Stack

Frontend

React (Vite)

Tailwind CSS

Axios

Backend

Spring Boot

Spring Security

JWT Authentication

JPA / Hibernate

Database

PostgreSQL

Payment

Khalti / Stripe (Test Mode)

👥 Roles

Admin → manages system

Agent → uploads tour packages

User → books services

🚀 How to Run Project

1️⃣ Clone repository

git clone https://github.com/YOUR_USERNAME/travelhub.git 

2️⃣ Backend Setup

cd backend 

Configure database inside:

src/main/resources/application.yml 

Run:

mvn spring-boot:run 

3️⃣ Frontend Setup

cd frontend npm install npm run dev 

Frontend will run on:

http://localhost:5173 

Backend will run on:

http://localhost:8080
